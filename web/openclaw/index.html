OpenClaw Mission Control --dev

Sandboxed OpenClaw cockpit for optional MBP lab use. Default profile is --dev.

Start / attach tmux

mission-openclaw
mission-openclaw --reset
mission-openclaw --no-attach

Start OpenClaw dev gateway

openclaw --dev gateway run \
  --port 19001 --bind loopback --auth none \
  --allow-unconfigured --verbose --compact

Loopback is safest. For direct tailnet exposure, use token auth. Do not expose --auth none broadly.

Static page vs live dashboard

This cheat sheet: port 4174. Live gateway UI after tunnel: 19001.

tmux navigation

Ctrl-b w      page picker
Ctrl-b 0-9    jump to numbered page in bottom bar
Ctrl-b arrows move panes
Ctrl-b z      zoom current pane
Ctrl-b d      detach

iMac over Tailscale

Static mission page:

http://MBP_TAILSCALE_IP:4174/

Safer gateway dashboard path from iMac via SSH/Tailscale tunnel:

ssh -N -L 19001:127.0.0.1:19001 -L 19003:127.0.0.1:19003 openclaw-mbp
# then open http://127.0.0.1:19001/ on iMac
