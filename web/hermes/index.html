Hermes Mission Control

Terminal-native cockpit for the stable Hermes gateway on the MBP control plane.

Start / attach tmux

mission-hermes
mission-hermes --reset
mission-hermes --no-attach

tmux navigation

Ctrl-b w      page picker
Ctrl-b 0-9    jump to numbered page in bottom bar
Ctrl-b arrows move panes
Ctrl-b z      zoom current pane
Ctrl-b d      detach

Ports

Hermes web page default: 4173

Hermes gateway default: 18789

Inspect on MBP:

ports
port-who 4173
hermes gateway status

iMac over Tailscale

From the iMac, browse to:

http://MBP_TAILSCALE_IP:4173/

If the page is not reachable, the web helper may not be running or macOS firewall may be blocking inbound traffic.
